The same lineup, ids and names as the files in `../` (the base set, which mimics Dispatcharr's Xtream output), re-encoded the way a
different third-party panel does it. A correct client must decode both sets into identical models (PLAN §6.8). Generated by
`tools/fixtures/gen-panel-b.py` from the base files; do not edit by hand.
